Deggos: A Curated Engineering Knowledge Base
Deggos is a custom-built video-sharing platform designed to centralize and organize high-quality educational content. By fetching and aggregating technical videos from YouTube and other online sources, the platform serves as a dedicated resource for mastering complex engineering concepts.

Key Features:
Curated Learning: Focused specifically on engineering degree requirements and technical skill-building.

Unified Access: Streamlines content from various web sources into one cohesive, distraction-free interface.

Academic Resource: Built to support rigorous study schedules and facilitate easy access to vital educational tutorials..
